# NotebookLM Quiz Interface

> 🇹🇷 Turkish documentation is available here: [README_TR.md](README_TR.md)

A Streamlit web application designed to parse and interactively render quizzes generated by NotebookLM. Users can upload text files containing specifically formatted test questions, solve them, and receive immediate feedback including rationales and document references.

## Important Note

This interface only works with NotebookLM quiz outputs generated using a specific prompt.

To use it:

1. Upload your sources to NotebookLM.
2. Paste the designated quiz-generation prompt into NotebookLM's chat.
3. Save NotebookLM's response as a `.txt` file.
4. Upload the `.txt` file to this interface or place it inside the `tests/` folder.

If you want to share the prompt, you can add a prompt link or redirect button inside the app.

## Features

- **Interactive Quiz UI:** Navigate through questions, select answers, and view scores in real time.
- **Instant Feedback:** Check answers instantly and view detailed explanations with document references.
- **File Upload Support:** Upload `.txt` files directly through the sidebar without needing to store them on the server.
- **Local Directory Parsing:** Automatically loads test files stored in the local `tests/` directory when the app starts.
- **Custom Styling:** Modern interface using a customized Streamlit theme and CSS injections.

## Installation

### 1. Clone the repository

```bash
git clone <repository-url>
cd <repository-directory>
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

If you do not have a `requirements.txt` file, install Streamlit manually:

```bash
pip install streamlit
```

### 3. Set up the project structure

Make sure your directory looks like this:

```text
project-root/
├─ app.py
├─ tests_parser.py
├─ requirements.txt
├─ .streamlit/
│  └─ config.toml
└─ tests/
   └─ sample-test.txt
```

> Note: If the `tests/` folder is empty and you want to keep it in GitHub, add a `.gitkeep` file inside it.

## Usage

### 1. Run the Streamlit application

```bash
streamlit run app.py
```

### 2. Prepare your test files

Use the designated prompt in NotebookLM to generate your quiz. Save the output as a `.txt` file.

### 3. Load the tests

You can load tests in two ways:

- Place `.txt` files inside the `tests/` folder for automatic loading.
- Upload `.txt` files directly from the sidebar while the app is running.

## Expected Test Format

The app expects NotebookLM outputs to follow a structured format similar to:

```text
### Question 1 [Remember | Easy] [—]
Question text here...

A) Option A
B) Option B
C) Option C
D) Option D
E) Option E

**Correct Answer:** C
**Document Reference:** Source document or section
**Rationale:** Explanation of the correct answer
```

Files that do not follow this structure may not be parsed correctly.
